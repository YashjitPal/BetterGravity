# Security Policy

BetterGravity modifies another installed application, so safety reports are treated as high priority.

Please do not publish an exploitable vulnerability in a public issue. Until a dedicated security contact is configured, open a private GitHub security advisory on the repository.

Reports should include the affected BetterGravity version, Antigravity version, operating system, reproduction steps, and whether original user files or credentials may be at risk. Never attach personal Antigravity data, tokens, credentials, or private configuration.

Community plugins and themes are not automatically trusted. The Marketplace design will require clear source links, declared permissions, compatibility metadata, and a reporting path before automatic third-party installation is enabled.
