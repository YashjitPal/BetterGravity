# Community Platform Direction

The installed BetterGravity runtime will eventually provide the community experience inside Antigravity. The Marketplace should be surfaced from the Antigravity sidebar, alongside the host's own navigation, rather than inside the standalone installer.

Community creators will be able to publish plugins implementing `@bettergravity/plugin-api` and themes implementing `@bettergravity/theme-api`, with source repositories, screenshots, documentation, licenses, and compatibility metadata.

Marketplace listings must declare an id, version, author, license, host compatibility, and repository URL. Permission declarations are expected for plugins that access sensitive host capabilities.
