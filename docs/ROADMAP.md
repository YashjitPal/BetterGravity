# Roadmap

## 0.1 · First Light

- Repository and package boundaries.
- Installer-only interface with Install, Update, Reinstall, and Repair.
- Safe preview patcher contract.
- Initial plugin, theme, and Marketplace data contracts.

## 0.2 · Native Installer

- Map supported Antigravity installation locations and update behavior.
- Detect versions and validate paths.
- Implement backup, rollback, atomic patching, and repair verification.
- Package the installer as a signed desktop application when release infrastructure is ready.

## 0.3 · Runtime Foundation

- Load the BetterGravity runtime inside Antigravity.
- Add settings and safe-mode recovery.
- Stabilize the public plugin and theme APIs.

## 0.4 · Community Preview

- Add the Marketplace entry to Antigravity's sidebar.
- Display source-linked plugins and themes.
- Add permissions, moderation, reports, compatibility checks, and signed catalog updates.

Dates are intentionally omitted until the Antigravity integration surface is understood.
